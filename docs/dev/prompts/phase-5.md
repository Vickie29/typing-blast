## 项目背景

「打字爆破」：词从屏幕顶部落下，敲对拼音/英文整词爆炸，心态值清零游戏结束。目前状态：核心玩法、粒子特效、合成音效全部完成。你做最后的**阶段 5：收尾**——暂停、彩蛋词、自定义词库编辑器、菜单最高分，以及整体 QA。

## 技术红线

1. 纯 vanilla HTML/CSS/JS，禁止任何依赖与网络请求
2. 本阶段可修改所有游戏文件，但发现前序代码 bug 时：**最小修复**并在交付说明中单独列出，不顺手重构
3. 所有文件 UTF-8；不引入任何素材文件

## 本阶段任务

### 1. 暂停

- PLAYING 中按 Esc：弹出暂停覆盖层（「继续」/「回到菜单」两个按钮），主循环冻结、画面定格
- window blur 或 visibilitychange 变 hidden 时自动进入暂停
- 暂停时不接受游戏输入（避免后台误触），但 Esc 可再次恢复

### 2. 彩蛋词

- 彩蛋词表：**下班、放假、发工资、下课**（按词的 main 文本匹配；若 WORKER_PACK 中缺「发工资」「下课」，按阶段 2 的格式约束补充进词库）
- 彩蛋词的气泡带**金色描边**，玩家能一眼认出来
- 打爆彩蛋词：全屏 5 连烟花（复用 fx.js 粒子，屏幕随机 5 个点依次彩色爆发）、`TB.Audio.play('firework')`、额外 +1000 分、全屏短暂闪光

### 3. 自定义词库编辑器（实现 index.html 中预留的 `#screen-editor`）

- 菜单第三个模式按钮解除置灰，点击进入编辑器
- **列表区**：显示现有自定义词（word + pinyin），每条带删除按钮
- **添加表单**：词（必填，≤12 字）、拼音（word 含中文时必填，纯英文可留空）；用 `TB.Words.validateEntry` 校验，失败时显示 reason，不写入
- **导入/导出**：导出把 `TB.Storage.exportCustom()` 的 JSON 放进文本框供复制；导入解析失败给友好提示且不破坏现有数据
- 从自定义模式开始游戏前检查：词库 ≥ 5 条才允许开局，不足时提示「至少录入 5 个词」并留在菜单

### 4. 菜单与结算打磨

- 菜单三个模式按钮下方各自显示该模式最高分（`TB.Storage.getBest`）
- 结算屏破纪录时显示醒目的「新纪录！」标记（阶段 3 若已实现则检查样式）
