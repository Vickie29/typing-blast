## 本阶段任务：实现 `js/game.js` 完整玩法

### 状态机

`MENU → PLAYING → OVER`（PAUSED 留给阶段 5）。游戏数据全部封装在 `TB.Game` 下，不散落全局变量。开局由菜单模式按钮触发，`TB.Game.start(mode)`。

### 实体 FallingWord

`{ typing, main, sub, progress = 0, x, y, speed, alive }`

- Canvas 绘制：气泡框 + 主文本 main（中文词/中文释义，大字）+ 下方小字 sub（拼音/英文）
- 已敲对部分：sub 的前 `progress` 个字符用高亮色区分（精致化交给阶段 4，本阶段颜色区分即可）
- 生成位置：x 随机（画布两侧各留 60px 边距），与现有词的水平位置至少错开 80px（随机重试 5 次取最远者即可）；y 从画布上方 -气泡高 进入

### 难度曲线（按此公式实现）

- 下落速度 `speed`（px/s）= `min(90, 26 + elapsedSec × 0.55)`（每个词生成时取当时的速度，生成后恒定）
- 生成间隔（ms）= `max(750, 2300 − elapsedSec × 11)`
- 同屏词数上限 = `min(8, 3 + floor(elapsedSec / 20))`

### 键盘输入（keydown 挂 window）

- 只响应 `/^[a-z]$/i`（忽略大小写），`preventDefault` 防止空格滚动等问题；另处理 Backspace 与 Esc
- **无锁定时**：在 alive 词中找 `typing[0] === key`，取 y 最大（最接近底部）的词锁定；无匹配则忽略（不惩罚）
- **有锁定时**：`key === typing[progress]` → progress + 1（调 `TB.Audio.play('hit')`）；不等 → combo 清零 + 该词红闪 300ms（调 `TB.Audio.play('wrong')`）
- Backspace / Esc：解除锁定，progress 保留不回退

### 判定与计分

- `progress === typing.length` → 爆炸：alive = false、消灭数 +1、combo +1、调 `TB.FX.explodeAt(x, y, sub)` 与 `TB.FX.floatText(x, y, '+' + 得分)`
- 单词得分 = `10 × typing.length × multiplier`，`multiplier = min(3, 1 + floor(combo / 10) × 0.5)`（combo 按完成词数累计）
- **连击回血**：combo 自增后达到 10 的倍数（10、20、30…）→ 心态值 +1（不超过 20；已满血则跳过，无任何反馈），HUD 心态条新恢复的段高亮，调 `TB.Audio.play('heal')`（阶段 4 才有实际声音，本阶段是空壳调用）
- 词落底（y 超过画布底 − 气泡高）：心态值 −1（初始 20）、全屏红边闪烁、combo 清零、调 `TB.Audio.play('hurt')`
- 心态值归 0 → 游戏结束：停循环，切结算屏，调 `TB.Storage.setBest` 更新最高分并记录是否新纪录

### HUD 与结算

- HUD 实时刷新：得分、坚持时间（秒）、combo（含当前倍率）、心态值（20 格分段条，随扣血变短变色）
- 结算屏显示真实数据：最终得分、坚持时间、消灭词数、最高 combo、最高分与新纪录标记
- 「再来一局」= 同模式清空所有实体与计时重来；「回到菜单」= 停止循环并切屏
- 移除或替换阶段 1 的「模拟游戏结束」调试按钮（改为真实触发游戏结束）

### 主循环

- requestAnimationFrame，`dt = min(50ms, 实际间隔)`，防止切标签页回来的 dt 尖峰
- 非游戏屏时停止 spawn 与渲染循环，不后台空转
- 实体用数组管理，死亡词及时移除，避免内存泄漏与"越玩越卡"
