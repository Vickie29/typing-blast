# 打字爆破 · 阶段 1/5：项目骨架与静态界面

> 使用方法：把本文件全文复制给 AI 即可开工。本阶段从零开始，目录里目前只有 README.md、WORKPLAN.md、prompts/。

## 项目背景

「打字爆破」是一个浏览器打字解压小游戏，面向上班族和大学生：让人血压升高的词（"对齐颗粒度""早八"）以消息弹窗样式从屏幕顶部落下，玩家敲对拼音整词爆炸；词落到底扣心态值（共 20 格），心态清零游戏结束。共有打工人（打拼音）、四六级（看中文释义打英文）、自定义（玩家自己录词）三种模式。总工程分 5 个阶段，你只做**阶段 1：静态骨架**。

## 技术红线（违反即返工）

1. 纯 vanilla HTML/CSS/JS。禁止任何框架、构建工具、npm 包、CDN 外链
2. 零后端、零网络请求；本阶段不使用 localStorage
3. 成品双击 index.html 即可运行（Chrome/Edge 桌面端）
4. 所有文件 UTF-8 编码，HTML 必须含 `<meta charset="UTF-8">`
5. 本阶段不实现任何游戏逻辑、词库、音效、粒子

## 本阶段任务

在项目根目录（本 README 所在目录）创建以下文件：

### 1. `index.html`

单页面，包含四块 `<section>` 屏幕，同屏只显示一个：

- `#screen-menu`：游戏大标题「打字爆破」、副标题一句话玩法（如"让血压升高的词从天而降，敲对拼音，当场爆炸"）、三个模式按钮（打工人模式 / 四六级模式 / 自定义词库——第三个置灰 + 角标"阶段 5 开放"）、底部最高分占位文本
- `#screen-game`：`<canvas id="game-canvas">` + 顶部 HUD 条（得分 / 时间 / 连击 / 心态值，先放占位值；心态值做成 20 格的横向分段条）+ 一个临时调试按钮「模拟游戏结束」（供验收跳到结算屏，阶段 3 会替换为真实触发）
- `#screen-editor`：本阶段空壳（一个空 section + 标题即可，阶段 5 实现）
- `#screen-result`：标题「心态爆炸」、四个数据位（最终得分 / 坚持时间 / 消灭词数 / 最高连击，假数据）、「再来一局」「回到菜单」两个按钮、最高分与「新纪录」占位

按顺序引入 `css/style.css`、`js/words.js`、`js/audio.js`、`js/fx.js`、`js/game.js`（后三个本阶段允许是占位空壳）。

### 2. `css/style.css`

- 视觉基调「办公室讽刺风」：浅色底 + 淡淡的日程表/日历网格底纹（用 CSS repeating-linear-gradient 等实现，不用图片）
- 屏幕切换：非激活 section `display: none`
- 预定义词气泡样式类 `.word-bubble`（阶段 3 的 Canvas 绘制不一定用到，先定义备查）
- 按钮、HUD、结算卡片基本样式；整体居中、留白舒适；中文字体正常显示

### 3. `js/game.js`

- 全局命名空间 `window.TB = {}`，后续阶段所有模块都挂到 TB 下
- `TB.Screens.show(name)`：切换到 `menu` / `game` / `result` / `editor`，互斥显示
- Canvas 自适应：铺满 `#screen-game` 可用区域、处理 devicePixelRatio（保证不糊）、监听 window resize 重算
- 渲染冒烟测试：requestAnimationFrame 循环常驻，在画布上画一个**静态**测试词气泡（词「对齐颗粒度」+ 下方拼音小字「dui qi ke li du」+ 气泡边框），证明中文文字渲染管线正常
- 按钮接线：菜单两个可用模式按钮 → 进入游戏屏；「模拟游戏结束」→ 结算屏（假数据）；结算屏「再来一局」→ 游戏屏、「回到菜单」→ 菜单屏

### 4. `js/words.js` / `js/audio.js` / `js/fx.js`

各只写一行注释占位（如 `// 阶段 2 实现`），保证 index.html 引入不报错。为了阶段 3 顺利，在 audio.js 和 fx.js 的占位里定义空函数：`TB.Audio = { play(){} }`、`TB.FX = { explodeAt(){}, floatText(){} }`。
