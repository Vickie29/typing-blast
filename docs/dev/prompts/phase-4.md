# 打字爆破 · 阶段 4/5：手感与音效

> 使用方法：把本文件全文复制给 AI。开工前先阅读 js/game.js（理解 TB.FX / TB.Audio 钩子的调用点）与 js/fx.js、js/audio.js 现状，确认阶段 3 已完成验收。

## 项目背景

「打字爆破」：词从屏幕顶部落下，敲对拼音/英文整词爆炸。阶段 3 已完成核心玩法（下落、锁定、爆炸、心态值、结算），目前爆炸只有钩子空函数，没有任何特效和声音。你只做**阶段 4：手感与音效**——目标是从"能玩"变成"解压"。combo 档位定义：0 档 <10、1 档 10–24、2 档 25–49、3 档 ≥50（按完成词数累计的 combo）。

## 技术红线

1. 纯 vanilla JS + Canvas 2D + WebAudio，禁止任何依赖
2. 修改范围：`js/fx.js`、`js/audio.js`、`js/game.js` 的接线部分（接必要的调用与参数，不重构玩法逻辑），以及 `index.html` / `css/style.css` 中新增「朗读设置」控件所需的最小改动
3. **仓库内不得出现任何 .mp3/.wav/.png/.jpg 素材文件**，所有声音实时合成
4. 所有文件 UTF-8；零网络请求

## 本阶段任务

### 1. `js/fx.js`（全部挂在 `TB.FX` 下）

- **粒子池**：上限 400，对象复用（不每帧 new）
- `explodeAt(x, y, text)`：把整词拆成**逐字符粒子**——text 每个字符一个粒子，随机初速 120~260 px/s（方向随机、整体偏上抛）、重力 600 px/s²、带旋转、生命 0.6~1.0s、透明度衰减至 0
- **combo 档位配色**：0 档橙色、1 档红色、2 档金色 + 一圈冲击波圆环、3 档彩虹（hue 随时间旋转）+ 更强冲击波。档位信息由 game.js 传入（函数签名可扩展为 `explodeAt(x, y, text, tier)`）
- `shake(power)`：屏幕震动，power = `4 + tier × 3` px，指数衰减约 300ms；实现为主循环渲染时 `ctx.translate` 随机偏移，包住全部游戏画面
- `floatText(x, y, text)`：飘字，上浮 40px、700ms 淡出；combo 里程碑时用大号字
- **里程碑文案**：combo 达到 10 / 25 / 50 时，屏幕中上方大字飘出「手速惊人」/「键盘冒烟」/「同事侧目」
- 提供 `update(dt)` 与 `render(ctx)`，由 game.js 主循环每帧调用

### 2. `js/audio.js`（全部挂在 `TB.Audio` 下，全部 WebAudio 合成）

- AudioContext **懒创建**：首次用户按键/点击时才创建并 `resume()`，避免 autoplay 警告
- 统一入口 `play(name, params)`，音色规格：
  - `'key'`：2ms 白噪声过 3kHz 高通，gain 0.15（每次敲键）
  - `'hit'`：正弦 660Hz、40ms 快速衰减（字母敲对）
  - `'wrong'`：方波 110Hz、90ms 过低通（错按）
  - `'explode'`（参数 tier 0–3）：白噪声 180ms 低通扫频 3000→200Hz + 55Hz 正弦 thump 150ms，总增益随 tier 增大
  - `'hurt'`：正弦 440→220Hz 双音下行 200ms（心态扣血）
  - `'heal'`：正弦双音上行 660→880Hz、各 90ms、柔和起音衰减（连击回血）
  - `'over'`：锯齿波 330→82Hz 滑音 600ms（游戏结束）
  - `'milestone'`：523 / 659 / 784Hz 三音上行琶音
  - `'firework'`：若干短噪声爆点 + 高频正弦闪烁（本阶段实现备用，阶段 5 彩蛋调用）
- **声音总开关（静音）**：三个入口——菜单屏显眼的「音效：开/关」控件（开局前就能关）、游戏内 Alt+M、HUD 静音按钮（M 是字母键，游戏内直接按会与打字输入冲突，因此游戏内必须用 Alt 前缀；菜单/结算等非游戏状态可直接按 M）；读写同一个 localStorage 键 `TB_MUTED`，三处状态始终一致、刷新保持。关闭立即生效：`play` 直接短路，并 `speechSynthesis.cancel()` 停止进行中的朗读。总开关优先于朗读设置——静音时即使朗读设为英文/中文也完全无声
- 全部音色过一个 master gain（0.9），静音即 master 置 0 或短路
- **单词朗读（speechSynthesis，浏览器内置本地语音，不引入任何素材）**：
  - `TB.Audio.speak(text, lang)`：lang 为 `'en-US'` 或 `'zh-CN'`；英文 rate 0.9、中文 rate 1.0
  - 语音选择：缓存 `getVoices()` 并监听 `voiceschanged` 更新；优先 `localService === true` 且 lang 匹配的语音；找不到时只设 `utterance.lang` 兜底（浏览器用默认语音）
  - 环境不支持 speechSynthesis：静默跳过，不报错
  - 队列控制：朗读按 speechSynthesis 原生行为排队；待播积压 ≥ 3 条时 `cancel()` 清空，防止越拖越远
  - 静音联动：静音时跳过新朗读，并 `speechSynthesis.cancel()` 停止进行中的朗读

### 3. `js/game.js` 接线（只加调用，不改判定规则）

- 敲键 → `play('key')`；字母正确 → `play('hit')`；爆炸 → `explodeAt(x, y, sub, tier)` + `play('explode', tier)` + `floatText('+得分')` + `shake(power)`
- **打爆词后的朗读**：仅四六级模式生效——按朗读设置调 `TB.Audio.speak`（读英文 = 英文单词 sub 文本、lang `'en-US'`；读中文 = 中文释义 main 文本、lang `'zh-CN'`）；打工人与自定义模式不朗读，只有爆炸音效
- **朗读设置**：三态「英文朗读（默认）/ 中文朗读 / 关闭」，存 localStorage 键 `TB_READING`；菜单放一个三选一设置控件，游戏内按 Alt+T 循环切换并在 HUD 短暂显示当前状态（T 是字母键，同样加 Alt 前缀）；两处入口读写同一个键，刷新保持；声音总开关关闭时朗读设置不生效（完全无声）
- 错按 → `play('wrong')`；落底扣心态 → `play('hurt')`；回血 → `play('heal')` + 绿色 `floatText('+1 心态')`（飘在心态条附近）+ 心态条新段绿色脉冲；里程碑 → `play('milestone')` + 大字文案；游戏结束 → `play('over')`
- 词气泡下落时轻微左右摆动（sin 摆动 ±3px，频率随该词 speed）
- 字母敲对的瞬间，该字母 scale 1.15 弹一下、100ms 回落（在 sub 文本渲染时实现）
- 渲染顺序：词气泡 → 粒子 → 飘字，全部包在震动 translate 内
