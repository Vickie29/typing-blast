## 一、项目背景（每个阶段都适用的通用信息）

**一句话玩法**：让人血压升高的词以「消息弹窗」样式从天而降，敲对拼音/拼写，当场爆炸。

**目标用户**：上班族、大学生。核心情绪价值：把日常最烦的词亲手敲碎，顺便练打字/背单词。

**三种模式**：

| 模式 | 屏幕显示 | 玩家输入 |
|---|---|---|
| 打工人 | 中文黑话 + 拼音注音 | 拼音（duiqikelidu） |
| 四六级 | 中文释义 | 英文单词 |
| 自定义 | 玩家自己录入的词 | 拼音（录入时填写）或字母 |

**核心机制**：

- 敲下第一个字母即自动锁定目标（同首字母中取最接近底部的）
- 打对的字母逐个点亮；整词打完 → 爆炸、得分、combo +1
- 连点爆破：同一词条累计点击 10 次 → 直接爆炸（与打字同等待遇，气泡右上角显示 N/10）
- 心态成长制：开局 1 格，每敲碎一个词 +1（上限 20，里程碑 5/10/15/20）；词落到底 −1；归零 → 游戏结束
- 同屏词数设置：菜单可调 1~8（默认 5），实际同屏数 = min(设置值, 难度爬升值)
- 四六级模式：打爆单词后自动朗读（英文单词/中文释义可切换，可关闭）；打工人与自定义模式为爆炸音效
- 声音总开关：菜单控件 / Alt+M / HUD 按钮三入口，一键关闭全部音效与朗读，设置持久化
- 错按 → 仅重置 combo，不扣心态
- 难度随时间上升：下落更快、出现更密

## 二、技术红线（任何阶段都不得违反）

1. 纯 vanilla HTML / CSS / JavaScript。禁止框架、构建工具、npm 包、CDN 外链
2. 零后端、零网络请求；数据只存 localStorage
3. 成品双击 `index.html` 即可运行（Chrome / Edge，桌面优先）
4. 所有文件 UTF-8 编码，HTML 含 `<meta charset="UTF-8">`
5. 音效用 WebAudio 实时合成；单词朗读用浏览器内置 speechSynthesis（本地语音）。不引入任何音频/图片素材文件
6. 只修改本阶段范围内的文件；发现前序阶段的 bug：**最小修复**并在交付说明中记录，不顺手重构
7. 每阶段完成时满足第七节 Definition of Done

## 三、目标目录结构

```
typing-blast/
├── index.html          # 唯一页面：菜单 / 游戏 / 结算 / 自定义词库编辑器（DOM 屏幕切换）
├── css/style.css       # 全部样式（办公室讽刺风：日程表底纹、消息气泡、心态值）
├── js/words.js         # 内置词库（打工人、四六级）+ localStorage 存取
├── js/audio.js         # WebAudio 音效合成（阶段 4 实现）
├── js/fx.js            # 粒子爆炸、屏幕震动、飘字（阶段 4 实现）
├── js/game.js          # 主循环、实体、键盘输入锁定、状态机、界面切换
├── README.md / WORKPLAN.md / prompts/
```

游戏画面 = Canvas；菜单 / 结算 / 编辑器 = DOM 覆盖层。全局命名空间 `window.TB`，各模块挂载其下（`TB.Screens`、`TB.Game`、`TB.Words`、`TB.Storage`、`TB.FX`、`TB.Audio`）。

## 四、交接协议（怎么把活交给 AI）

1. **一次只交一个阶段**：把 `prompts/phase-N.md` 全文复制给 AI（新会话即可，指令是自包含的）
2. 阶段 2~5 的指令会要求 AI 先阅读仓库现有文件；接手前确认上一阶段已验收
3. AI 交付后，**人工执行该阶段验收清单**，全部通过才进入下一阶段
4. 验收不通过：把未通过项原样发回给 AI 修复；不要带着问题跳阶段
5. 阶段之间可以随时换 AI / 换会话

## 六、各阶段详情

### 阶段 1：骨架与界面
**范围**：三块 DOM 屏幕（菜单 / 游戏画布 / 结算）+ Canvas 初始化 + 屏幕切换器。不实现任何玩法。
**要点**：菜单含三个模式按钮（自定义置灰）；游戏屏含 Canvas + HUD 占位 + 临时「模拟游戏结束」调试按钮；结算屏假数据占位；Canvas 适配 devicePixelRatio 与窗口 resize；rAF 常驻并画一个静态测试词气泡冒烟。自定义词库编辑器屏幕留空壳。
**验收**：双击打开零报错；三屏按钮全路径可走通；中文显示正常；resize 不糊；无任何外部请求。

### 阶段 2：词库与数据层
**范围**：只写 js/words.js。
**要点**：WORKER_PACK ≥70 条（含彩蛋词「下班」「放假」，typing 串仅 a–z、包内不重复，排除 996 等数字词）；CET6_PACK ≥80 条；统一 API `TB.Words.getPack(mode)` 返回 `[{main, sub, typing}]`；`pick()` 避开最近 8 条；`TB.Storage` 提供最高分、自定义词库 CRUD、导入导出；`validateEntry` 供阶段 5 编辑器用。
**验收**：console 抽查数量与格式；localStorage 读写往返正确；模式间最高分隔离。

### 阶段 3：核心游戏循环
**范围**：只改 js/game.js（必要时微调 index.html 的 HUD）。
**要点**（数值已定，照做）：speed = min(90, 26 + 秒×0.55) px/s；spawn 间隔 = max(750, 2300 − 秒×11) ms；同屏上限 = min(8, 3 + ⌊秒/20⌋)；心态值 20 格，连击回血（combo 达 10 的倍数 +1，上限 20，满血不触发）；单词得分 = 10 × 字母数 × 倍率，倍率 = min(3, 1 + ⌊combo/10⌋×0.5)；锁定规则 = 同首字母取 y 最大；错按只清 combo；Backspace/Esc 解锁保留进度；dt 钳制 50ms；结算屏真实数据 + 最高分持久化。FX/Audio 以空函数钩子接入（阶段 4 实现）。
**验收**：两种内置模式端到端可玩、可重开；锁定/错按/落底/回血/结算规则全部正确；连续 5 局无报错无实体残留。

### 阶段 4：手感与音效
**范围**：js/fx.js、js/audio.js + game.js 接线。
**要点**：逐字符粒子爆炸（池上限 400）、combo 四档配色（橙/红/金/彩虹）与冲击波、屏幕震动随档位增强、飘字与里程碑文案（10「手速惊人」/25「键盘冒烟」/50「同事侧目」）；WebAudio 全合成音色（敲键/命中/错按/爆炸/扣血/回血/结束/里程碑/烟花，具体参数见指令）；四六级模式打爆词后 speechSynthesis 朗读单词（英文/中文可切换、可关闭、设置持久化）；声音总开关（菜单控件 + Alt+M + HUD 按钮）持久化，一键关闭全部音效与朗读；词气泡下落摆动、字母命中弹跳。
**验收**：仓库零素材文件；声音总开关三入口状态一致、关闭后整局无声（含朗读）、刷新保持；朗读语言可切换、刷新保持；10 词同屏目测流畅；档位特效肉眼可辨。

### 阶段 5：收尾与彩蛋
**范围**：全部文件。
**要点**：Esc 暂停 + 失焦自动暂停；彩蛋词（下班/放假/发工资/下课）金色描边、全屏 5 连烟花 +1000；自定义词库编辑器（增删/校验/导入导出、≥5 词才能开局）；菜单显示各模式最高分；结算新纪录标记；整体 QA 并校正 README。
**验收**：见 prompts/phase-5.md 的完整 QA 清单。
